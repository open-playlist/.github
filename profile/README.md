# Open Playlist

Open Playlist is part of [Synctune](https://github.com/synctune-io), focused on open standards and software for portable music playlists. Our mission is music without walls: listeners should be able to move, share, and keep their playlists without platform lock-in.

## Projects

| Repository | Focus |
| --- | --- |
| [open-playlist-spec](https://github.com/open-playlist/open-playlist-spec) | The open playlist format and specification, renamed from `open-playlist`. |
| [open-playlist-engine](https://github.com/open-playlist/open-playlist-engine) | The reference implementation and cross-service playlist migration engine. |
| [open-playlist-manifesto](https://github.com/open-playlist/open-playlist-manifesto) | The principles behind music without walls and listener ownership. |

Repository links use their planned organization locations. Some may be private or pending transfer.
